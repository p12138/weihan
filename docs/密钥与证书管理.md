# 密钥与证书管理（自用分发版）

> 原则：**只给生成与配置方法，不代收、不落盘、不写入任何私钥或密码明文**。
> 本文件与整个补充包内，所有凭证字段都是占位符或环境变量引用。

---

## 1. Android：一份 keystore 用到底

| 项 | 说明 |
|---|---|
| 生成 | 本机执行 `bash scripts/make_keystore.sh`，`keytool -genkeypair`，RSA 2048、有效期 10000 天 |
| 存放 | `android/app/selfuse.jks`，**只留在本机与加密备份中** |
| 引用 | 本机用 `android/key.properties`；CI 用 `ANDROID_KEYSTORE_B64` 等 Secrets |
| 丢失后果 | 无法覆盖升级已安装的包，朋友得卸载重装；自用可接受，但务必备份 |
| 与上架的区别 | 不需要 Play App Signing 上传密钥，也不需要 AAB；自用 APK 直接由这份 keystore 签 |

**CI Secrets 清单（Android）**

| Secret | 内容 | 怎么来 |
|---|---|---|
| `ANDROID_KEYSTORE_B64` | keystore 的 base64 | `base64 -w0 android/app/selfuse.jks`（Linux）/ `base64 -i ... \| tr -d '\n'`（macOS） |
| `ANDROID_KEYSTORE_PASS` | 库密码 | 密码管理器 |
| `ANDROID_KEY_ALIAS` | 别名，默认 `selfuse` | 生成时指定 |
| `ANDROID_KEY_PASS` | 密钥密码 | 密码管理器 |

> 工作流在 Secrets 缺失时**明确降级**为 debug 签名并打 notice，不会伪装成 release，也不会静默失败。

## 2. iOS：证书 / 描述文件体系

| 资产 | 用途 | 自用分发怎么选 |
|---|---|---|
| Apple Developer 账号 | 签名资格 | 约 ¥688/年；没有就只能出未签名 .app |
| Development 证书 | 开发调试装真机 | 免费个人签名亦可用，7 天过期 |
| Distribution 证书（.p12） | 出可分发 IPA | Ad Hoc 与 TestFlight 都需要 |
| App ID / Bundle ID | 应用标识 | 必须与工程 `PRODUCT_BUNDLE_IDENTIFIER` 一致 |
| Ad Hoc Provisioning Profile | 绑定证书 + 设备 UDID | 上限 100 台，换设备要重生成 |
| ExportOptions plist | 告诉 xcodebuild 用哪种方式导出 | 本包给了 `ad-hoc` 与 `development` 两份 |

**CI Secrets 清单（iOS）**

| Secret | 内容 |
|---|---|
| `IOS_P12_BASE64` | Distribution 证书 .p12 的 base64 |
| `IOS_P12_PASSWORD` | 导入 .p12 的密码 |
| `IOS_PROVISION_B64` | .mobileprovision 的 base64 |
| `IOS_KEYCHAIN_PASSWORD` | CI 临时钥匙串密码（可随机生成，仅本次构建用） |

工作流会在 macOS runner 上创建**临时钥匙串**、导入证书、按 UUID 安装描述文件，构建结束随 runner 销毁；不会把证书写进仓库或产物。

---

## 4. 绝不落地的东西

- keystore / p12 / 证书 / 描述文件的**二进制内容**
- 任何明文密码、PAT、讯飞 AppID/APIKey/APISecret
- 任何可还原凭证的 base64 字符串

这些都只存在于：你的密码管理器、本机加密备份、CI 平台的 Secrets 里。

---

## 5. 与「正式上架」的差异提醒

| 项 | 自用 | 上架 |
|---|---|---|
| Android 签名 | 本地 keystore，自己保管 | Play App Signing 托管 + 上传密钥 |
| 密钥泄露影响 | 别人可伪造你的自用包 | 可能冒名发布，后果严重 |
| 讯飞密钥 | `--dart-define` 编译进二进制，可逆向，自用可接受 | 必须改为后端签发已签名 wss URL |
| 证书管理 | 手工 / 本包工作流 | 建议 Fastlane Match 统一托管 |

> 交接文档已明确：`--dart-define` 不等于加密。自用内测没问题；一旦决定上架，替换 `XfyunSocketConnector` 即可，协议层不用动。
